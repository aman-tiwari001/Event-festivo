# 🎟️ EventÓfestivo

**EventÓfestivo** is a blockchain-powered dApp built on the Diamante blockchain, revolutionizing the way you book tickets for events like concerts 🎸. EventÓfestivo ensures that each ticket is a unique digital asset 🛡️, securely transferred to your account upon purchase 💳.


## Problem It Solves

### 1. Lack of Transparency
Traditional ticketing platforms often suffer from opaque pricing models and availability issues. Users are frequently faced with hidden fees and unclear ticket distribution processes. EventÓfestivo solves this by recording all ticket transactions on the Diamante blockchain, ensuring full transparency in pricing, availability, and distribution.

### 2. High Risk of Fraud and Counterfeit Tickets
Fraudulent ticket sales and counterfeit tickets are major problems in the event industry, leading to financial losses for buyers and damaged reputations for organizers. By tokenizing tickets on the blockchain, EventÓfestivo ensures that each ticket is unique, verifiable, and secure, eliminating the risk of fraud.

### 3. Limited Support for Artists
Many existing platforms do not prioritize the needs of artists, often leading to unfair compensation and limited promotional opportunities. EventÓfestivo empowers artists by offering them direct engagement with their audience, fair revenue distribution, and tools to promote their events effectively.

### 4. Inefficient Secondary Market
The secondary market for event tickets is plagued by scalping, inflated prices, and lack of security. EventÓfestivo provides a transparent and secure marketplace for reselling tickets, ensuring that all transactions are fair and verifiable.

---


## 🚀 Features

- **Secure Ticketing**: Each event ticket is a unique asset on the blockchain, ensuring security and authenticity 🔒.
- **Transparent Transactions**: All transactions are recorded on the Diamante blockchain, providing full transparency 🌐.
- **Ownership of Assets**: Tickets are transferred directly to your account as digital assets, giving you full ownership 🎫.
- **Decentralized**: No middlemen—experience true peer-to-peer ticket buying 🤝.

## 📦 Installation

1. **Clone the repository**:
    ```bash
    git clone https://github.com/yourusername/EventOfestivo.git
    cd EventOfestivo
    ```

2. **Install dependencies for backend and frontend**:
    ```bash
    npm install
    ```

3. **Run the development server**:
    ```bash
    npm run start //for backend
    npm run dev //for frontend
    ```

## 🛠️ Usage

1. **Connect your wallet**: Use Diamante wallet or create a new account on the Diamante blockchain.
2. **Browse events**: Discover events and select the ones you want to attend 🎫.
3. **Purchase tickets**: Buy tickets by giving Diam tokens and receive them as assets directly in your wallet 💼.
4. **View your tickets**: Check your account to see the tickets you've purchased, securely stored as digital assets 🛡️.
